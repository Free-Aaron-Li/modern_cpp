# 第 2 章 用户自定义类型

## 2.1 引言（Introduction）

---
使用*基本类型*（如 `int`、`double`、`char`）、`const` *修饰符*和*声明操作符*（如 `&`、`*`、`[]`）构造出的类型称为**内置类型**
（built-in types）。

C++ 在内置类型及其操作的基础上增加了一套精致的*抽象机制*（abstraction
mechanism），据此构造所需的高层设施。抽象机制的主要目的是令程序员可以设计并实现他们自己的数据类型。利用这种机制从其他类型构造出来的类型称为
**用户自定义类型**（user-defined types）。

用户自定义类型可以基于内置类型构造，也可以基于其他用户自定义类型构造。其相较于内置类型，更易用、更不易出错，而且通常与内置类型实现相同功能一样高效，甚至更快。

本章主要介绍 C++ 中四种基本的用户自定义类型：结构体（struct）、类（class）、枚举（enum）和联合（union），当然碍于篇幅仅作简单介绍。

## 2.2 结构体（struct）

---
`struct` 是 C++ 中最简单的用户自定义类型，它将一组不同类型的元素组合在一起。

- **定义**：使用 `struct` 关键字。
- **成员访问**：使用点运算符（`.`）访问成员；如果通过指针访问，则使用箭头运算符（`->`）。参见 `ch2_structs_impl::f()`。
- **Vector 初始化**：展示如何分配内存。参见 `ch2_structs_impl::vector_init()`。
- **读取与求和**：参见 `ch2_structs_impl::read_and_sum()`。
- **初始化**：可以使用花括号 `{}` 进行列表初始化。

在 `Vector` 示例中，我们演示了如何使用 `new` 运算符从**自由存储**（free store，也称为**动态内存**或**堆**）分配空间。通过
`new` 分配的对象的生存期独立于其创建时的作用域，并持续存在，直至被显式地用 `delete` 销毁。

在 C++ 中，`struct` 与 `class` 的唯一区别是默认访问权限：`struct` 成员默认为 `public`，而 `class` 成员默认为 `private`。

代码参考：[2_2_structs.cpp](../2_user_defined_types/src/2_2_structs.cpp)

## 2.3 类（class）

---
如果希望自定义的类型易于使用和修改（即维护）、希望数据具有一致性、希望形式上最好对用户不可见，那么最理想的做法是将类型接口与其实现分离，而非上述的数据与操作分离，恰恰相反，在这时为表明二者具备紧密联系应处于同一作用域内。实现上述目的的语言机制被称为
*类*。类含有一系列成员，可以是数据、函数或类型。

`class` 用于定义具有严密接口和私有实现的对象。它通过访问控制关键字实现封装：

- **public**：定义对象的公共接口，外部代码可以访问。
- **private**：隐藏实现细节，仅限类内部成员函数访问。
- **构造函数**：与类同名的特殊成员函数，用于初始化对象。参见 `ch2_classes_impl::Vector::Vector()`。
- **成员函数**：例如 `ch2_classes_impl::Vector::size()`。
- **读取与求和**（类版本）：参见 `ch2_classes_impl::read_and_sum()`。

通过将数据成员设为 `private`，我们可以确保对象的状态始终满足特定的不变式（Invariants）。

> 按照惯例，通常将 `public` 声明放在前面，把 `private` 声明放在后面，除非需要特别强调 `private` 成员的实现。

C++ 处理可变数量信息的一项基本技术：一个固定尺寸的句柄（如 `Vector` 对象）指向位于“别处”的一组数量可变的数据（如 `Vector`
中的通过 `new` 分配的元素）。

代码参考：[2_3_classes.cpp](../2_user_defined_types/src/2_3_classes.cpp)

## 2.4 枚举（enum）

---
枚举（enum）是一种简单的用户自定义类型，用于表示少量整数数值的集合。通过使用符号（或助记符）名称替代整数，枚举值可以提升代码的可读性，降低潜在错误。

- **枚举类（enum class）**：强类型枚举（Scoped Enums），具备独立作用域，推荐使用。参见 `ch2_enums_impl::Color`
  。它们不会隐式转换为整数，且成员名局限在枚举名的作用域内。
- **交通灯示例**：参见 `ch2_enums_impl::Traffic_light`。
- **普通枚举（enum）**：传统 C 风格枚举，成员名会泄露到外部作用域，且容易发生意外的整数转换。

`enum class` 定义且仅定义赋值操作符、初始化函数及比较操作符，其他操作符可自定义。例如为枚举定义运算符（如 `++`
），从而使其表现得像内置类型，参考 `ch2_enums_impl::operator++()`。

> 默认枚举值的整数数值从 `0` 开始，除非显式指定，后续逐个加一。

代码参考：[2_4_enums.cpp](../2_user_defined_types/src/2_4_enums.cpp)

## 2.5 联合（union）

---
`union` 是一种特殊的 `struct`，其所有成员被分配在同一块内存区，即实际所占空间等于最大成员的大小。显然，同一时刻 `union`
只能存储其中一个成员。

- **目的**：节省空间（一次只能使用其中一个成员）。参见 `ch2_unions_impl::Entry`。
- **局限**：程序员必须自行跟踪当前存储的是哪个成员，容易出错。参见 `ch2_unions_impl::print_entry()`。
- **现代替代方案**：标准库提供的 `std::variant` 是类型安全的联合替代品，推荐在现代 C++ 中使用，参考
  `ch2_unions_impl::print_entry1()`。

> 在很多使用场景中，`variant` 都比 `union` 更简单、安全。

代码参考：[2_5_unions.cpp](../2_user_defined_types/src/2_5_unions.cpp)
