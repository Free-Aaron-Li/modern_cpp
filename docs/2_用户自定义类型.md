# 第 2 章 用户自定义类型

## 2.1 引言（Introduction）

---

使用 *基本类型*（如 `int`、`double`、`char`）、`const` *修饰符* 和 *声明操作符*（如 `&`、`*`、`[]`）构造出的类型称为**内置类型**
（built-in types）。

C++ 在内置类型及其操作的基础上增加了一套精致的 *抽象机制*（abstraction
mechanism），据此构造所需的高层设施。抽象机制的主要目的是令程序员可以设计并实现他们自己的数据类型。利用这种机制从其他类型构造出来的类型称为
**用户自定义类型**（user-defined types）。

用户自定义类型可以基于内置类型构造，也可以基于其他用户自定义类型构造。其相较于内置类型，更易用、更不易出错，而且通常与内置类型实现相同功能一样高效，甚至更快。

本章主要介绍 C++ 中四种基本的用户自定义类型：结构体（struct）、类（class）、枚举（enum）和联合（union），当然碍于篇幅仅作简单介绍。

## 2.2 结构体（struct）

---

`struct` 是 C++ 中最简单的用户自定义类型，它将一组不同类型的元素组合在一起。

- **定义**：使用 `struct` 关键字。
- **成员访问**：使用点运算符（`.`）访问成员；如果通过指针访问，则使用箭头运算符（`->`）。参见 `ch2_structs_impl::f()`。

### 涉及的函数与类：

- **`struct Vector`**
	- **定义**：`struct ch2_structs_impl::Vector`
	- **用途**：简单的向量结构体，包含指向 `double` 的指针 `elem` 和大小 `sz_`。
- **`vector_init(Vector& v, int s)`**
	- **签名**：`void ch2_structs_impl::vector_init(Vector& v, int s)`
	- **用途**：使用 `new` 从堆上分配 `s` 个元素的内存，并初始化 `Vector`。
- **`read_and_sum(int s)`**
	- **签名**：`double ch2_structs_impl::read_and_sum(int s)`
	- **用途**：创建 `Vector`，从标准输入读取 `s` 个元素，计算并返回它们的总和。
- **`f(Vector v, Vector& rv, Vector* pv)`**
	- **签名**：`void ch2_structs_impl::f(Vector v, Vector& rv, Vector* pv)`
	- **用途**：演示通过值、引用和指针三种方式访问结构体成员。
- **`tutorial_structs()`**
	- **签名**：`void tutorial_structs()`
	- **用途**：2.2 节教程入口，演示结构体定义、初始化及成员访问。

## 2.3 类（class）

---

如果希望自定义的类型易于使用和修改（即维护）、希望数据具有一致性、希望形式上最好对用户不可见，那么最理想的做法是将类型接口与其实现分离，而非上述的数据与操作分离。恰恰相反，在这时为表明二者具备紧密联系应处于同一作用域内。实现上述目的的语言机制被称为
*类*。类含有一系列成员，可以是数据、函数或类型。

`class` 用于定义具有严密接口和私有实现的对象。它通过访问控制关键字实现封装：

### 涉及的函数与类：

- **`class Vector`**
	- **定义**：`class ch2_classes_impl::Vector`
	- **用途**：封装了 `elem` 和 `sz` 的类。
- **`Vector::Vector(int s)`**
	- **签名**：`ch2_classes_impl::Vector::Vector(int s)`
	- **用途**：构造函数，初始化 `Vector` 并分配内存。
- **`Vector::operator[](int i)`**
	- **签名**：`double& ch2_classes_impl::Vector::operator[](int i)`
	- **用途**：下标运算符重载，提供对元素的引用访问。
- **`Vector::size()`**
	- **签名**：`int ch2_classes_impl::Vector::size()`
	- **用途**：获取向量大小。
- **`read_and_sum(int s)`**
	- **签名**：`double ch2_classes_impl::read_and_sum(int s)`
	- **用途**：使用 `Vector` 类实现的读取与求和。
- **`tutorial_classes()`**
	- **签名**：`void tutorial_classes()`
	- **用途**：2.3 节教程入口，演示类封装、构造函数及接口设计。

代码参考：[2_3_classes.cpp](../2_user_defined_types/src/2_3_classes.cpp)

## 2.4 枚举（enum）

---

枚举（enum）是一种简单的用户自定义类型，用于表示少量整数数值的集合。通过使用符号（或助记符）名称替代整数，枚举值可以提升代码的可读性，降低潜在错误。

### 涉及的运算符与类：

- **`enum class Color`**
	- **定义**：`enum class ch2_enums_impl::Color`
	- **用途**：强类型颜色枚举。
- **`enum class Traffic_light`**
	- **定义**：`enum class ch2_enums_impl::Traffic_light`
	- **用途**：强类型交通灯枚举。
- **`operator++(Traffic_light& t)`**
	- **签名**：`Traffic_light& ch2_enums_impl::operator++(Traffic_light& t)`
	- **用途**：为交通灯定义自增运算符，演示如何为枚举自定义操作。
- **`tutorial_enums()`**
	- **签名**：`void tutorial_enums()`
	- **用途**：2.4 节教程入口，演示强类型枚举及其优势。

代码参考：[2_4_enums.cpp](../2_user_defined_types/src/2_4_enums.cpp)

## 2.5 联合（union）

---

`union` 是一种特殊的 `struct`，其所有成员被分配在同一块内存区，即实际所占空间等于最大成员的大小。显然，同一时刻 `union`
只能存储其中一个成员。

### 涉及的函数与类：

- **`union Value`**
	- **定义**：`union ch2_unions_impl::Value`
	- **用途**：联合体，可在同一内存位置存储 `int*` 或 `int`。
- **`struct Entry`**
	- **定义**：`struct ch2_unions_impl::Entry`
	- **用途**：包含名字、类型标记 (`Type`)、联合体 (`Value`) 以及现代替代方案 `std::variant` 的结构体。
- **`print_entry(const Entry& e)`**
	- **签名**：`void ch2_unions_impl::print_entry(const Entry& e)`
	- **用途**：演示手动根据类型标记访问联合体成员的传统方式。
- **`print_entry1(const Entry& e)`**
	- **签名**：`void ch2_unions_impl::print_entry1(const Entry& e)`
	- **用途**：演示使用 `std::variant` 和 `holds_alternative` 进行类型安全访问的现代方式。
- **`tutorial_unions()`**
	- **签名**：`void tutorial_unions()`
	- **用途**：2.5 节教程入口，对比联合体与 `std::variant`。

代码参考：[2_5_unions.cpp](../2_user_defined_types/src/2_5_unions.cpp)
