# 第 2 章 用户自定义类型

## 2.1 引言

C++ 的核心优势之一是能够通过组合内置类型和其它用户自定义类型来构建新的类型。 本章主要介绍 C++
中四种基本的用户自定义类型：结构体 (struct)、类 (class)、枚举 (enum) 和联合 (union)。

内容参考自 Bjarne Stroustrup 的《C++ 之旅》(A Tour of C++)。

## 2.2 结构体 (struct)

`struct` 是 C++ 中最简单的用户自定义类型，它将一组不同类型的元素组合在一起。

- **定义**：使用 `struct` 关键字。
- **成员访问**：使用点运算符 (`.`) 访问成员；如果通过指针访问，则使用箭头运算符 (`->`)。
- **初始化**：可以使用花括号 `{}` 进行列表初始化。

在 C++ 中，`struct` 与 `class` 的唯一区别是默认访问权限：`struct` 成员默认为 `public`，而 `class` 成员默认为 `private`。

代码参考：[2_2_structs.cpp](../2_user_defined_types/src/2_2_structs.cpp)

## 2.3 类 (class)

`class` 用于定义具有严密接口和私有实现的对象。它通过访问控制关键字实现封装：

- **public**：定义对象的公共接口，外部代码可以访问。
- **private**：隐藏实现细节，仅限类内部成员函数访问。
- **构造函数**：与类同名的特殊成员函数，用于初始化对象。

通过将数据成员设为 `private`，我们可以确保对象的状态始终满足特定的不变性（Invariants）。

代码参考：[2_3_classes.cpp](../2_user_defined_types/src/2_3_classes.cpp)

## 2.4 枚举 (enum)

枚举用于表示一组命名的常量值。

- **枚举类 (enum class)**：强类型枚举（Scoped Enums），推荐使用。它们不会隐式转换为整数，且成员名局限在枚举名的作用域内。
- **普通枚举 (enum)**：传统 C 风格枚举，成员名会污染外部作用域，且容易发生意外的整数转换。

C++ 允许为枚举定义运算符（如 `++`），从而使其表现得像内置类型。

代码参考：[2_4_enums.cpp](../2_user_defined_types/src/2_4_enums.cpp)

## 2.5 联合 (union)

`union` 是一种特殊的结构，其所有成员分配在同一块内存地址。

- **目的**：节省空间（一次只能使用其中一个成员）。
- **局限**：程序员必须自己跟踪当前存储的是哪个成员的值，容易出错。
- **现代替代方案**：标准库提供的 `std::variant` 是类型安全的联合替代品，推荐在现代 C++ 中使用。

代码参考：[2_5_unions.cpp](../2_user_defined_types/src/2_5_unions.cpp)

## 2.6 建议

- 优先使用 `class` 而非 `struct` 来表示具有不变性的实体。
- 优先使用 `enum class` 而非普通 `enum`。
- 尽量避免直接使用 `union`，考虑使用 `std::variant`。
