# 智能指针概说 {#smart_pointer_doc}

## 1. 内存管理 {#mem_mgmt_sec}

==堆==：heap，指的是动态分配内存的区域。操作堆用以下两种方式进行：

- `new` 和 `delete`
- `malloc` 和 `free`

==栈==：stack，指的是函数调用过程中产生的本地变量和调用数据区域。这个栈和数据结构的栈相似，都满足后进现出。

## 2. RAII {#raii_sec}

==RAII==，Resource Acquisition Is Initialization（资源获取即初始化），是
C++所特有的资源管理方式，它依托栈和析构函数，来对所有的资源（包括堆内存在内）进行管理。它提供了一种异常安全的资源管理方式，对
RAII 的使用，使 C++不需要类似于 Java 那样的垃圾收集方法，也能有效的内存管理。

```cpp
std::mutex mtx;
void foo(){
	std::lock_guard<std::mutex> lock(mtx);
	// ...
}
```

## 3. `shared_ptr` { #sp_detail_sec }

智能指针的基本原理就是通过 RAII 实现对内存的管理，从 C++11 开始已经不推荐再使用裸指针。智能指针支持裸指针的所有操作，如：
`*` 、 `++` 、 `--` 、 `+=` 、 `<` 、 `>` 等。C++11 引入 `shared_ptr` 、 `unique_ptr` 、 `weak_ptr` ，（还可以算上 Boost 库中的
`scoped_ptr` ）。三种指针所管理的对象代表了不同所有权，适用于不同的场景。

### 3.1 shared_ptr 概述 {#sp_overview_sec}

共享所有权，具有复制语义，多个 `shared_ptr` 指向同一个对象时，每个 `shared_ptr` 的引用计数都会记录指向该对象的 `shared_ptr`
的数量，当最后一个指向对象（和共享计数）的 `shared_ptr` 析构时，它会删除对象和共享技术，通过 `use_count` 方法可以获取
`shared_ptr` 对象的共享计数值。

注意⚠️：

- 避免通过一个裸指针创建多个 `shared_ptr` 对象；
- 避免通过 `this` 指针创建 `shared_ptr` 对象。

### 3.2 shared_ptr 的细节 {#sp_detail_subsec}

1. `std::shared_ptr` 的尺寸大于裸指针，一般是裸指针的两倍，因为它内部既包含一个指向到资源的裸指针，也包含一个指向该资源的引用计数的裸指针；
2. 引用计数的内存是动态分配的；
3. 引用计数的递增和递减是原子操作。

## 4. `weak_ptr`

`weak_ptr` 用来表示临时所有权（弱引用，不会增加引用计数），它需要配合 `shared_ptr` 使用，追踪 `shared_ptr` 所管理的对象是否有效，当需要==临时所有权时==，则将其转换为 `shared_ptr` ，这样对象的引用计数会加 1，来保证正在访问的对象有效性，它有三个关键函数： `use_count()` ， `expired()` ， `lock()` 。

`weak_ptr` 具有复制语义，==可以通过一个 `weak_ptr` 对象构造另一个 `weak_ptr` 对象，通过一个 `shared_ptr` 构造一个 `weak_ptr` 对象==。
