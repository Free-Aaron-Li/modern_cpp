## 1.1 引言

本章节主要展示 C++ 符号、内存和计算模型，内容参考自 Bjarne Stroustrup 的《C++ 之旅》（A Tour of C++）。

## 1.2 程序

ISO C++ 定义了两种实体：

- **核心语言特性**：例如内置类型（如 `int` 和 `double`）和循环（如 `for` 语句）。
- **标准库组件**：例如容器（如 `vector` 和 `map`）和 I/O 操作（如 `cout` 和 `cin`）。

在 C++ 程序中，`main()` 函数是执行的入口。我们可以通过定义辅助函数来模块化代码。

### 示例函数：

- `square()`：计算并返回 `x` 的平方。
- `print_square()`：调用 `square` 并通过 `std::cout` 打印结果。

代码参考：[1_2_program.cpp](../1_basics/src/1_2_program.cpp)

## 1.3 函数

函数是执行某些计算的代码块，是实现模块化的基本手段。

- **返回类型**：函数返回值的类型，若无返回值则为 `void`。
- **参数**：传递给函数的值，支持传值、传引用等多种方式。

### 函数重载 (Overloading)

C++ 允许定义同名但参数列表（签名）不同的多个函数。编译器会根据调用时的实际参数自动匹配最合适的版本。

注意：如果匹配存在歧义（例如调用 `print(1, 2)` 时两个版本都需等价转换），编译器将报错。

### 示例函数：

- `print(int, double)`：演示接受整数和浮点数参数的函数重载。
- `print(double, int)`：演示接受浮点数和整数参数的函数重载，与前者构成重载。

代码参考：[1_3_functions.cpp](../1_basics/src/1_3_functions.cpp)

## 1.4 类型、变量与算术

C++ 是一种静态类型语言，每个实体（对象、值、变量等）在被使用前必须有明确的类型。

- **内置类型**：`bool`, `char`, `int`, `double` 等。硬件决定了每种类型的固定尺寸。
- **sizeof 运算符**：可以获取类型或对象在内存中占用的字节数。
- **字面量**：支持多种进制表示，如二进制 (`0b101`)、十六进制 (`0xFF`)、八进制 (`077`)。可以使用单引号 (`'`)
  作为数字分隔符（C++14），提高长数字的可读性。
- **初始化**：推荐使用 `{}` 进行统一初始化（Uniform Initialization），它可以防止窄化转换。

### 初始化

C++ 提供一种通用形式，用花括号括起来并用逗号分隔的初始化列表。

使用 `=` 是 C 语言传统方式，建议使用更通用的 `{}`，这种形式可以避免隐式类型转换导致的信息丢失（*窄化类型转换*），例如
`initialization_list()`。

当变量的类型可以从初始化符号中推导，建议使用 `auto`。这时倾向于使用 `=` 符号，【此时没有类型转换问题风险】。

那么该何时使用 `auto`？

1. 该定义的作用域较大，希望读者能清楚其类型；
2. 初始化表达式类型不是显而易见的；
3. 希望明确规定某个变量的范围和精度（如 `float` 和 `double`），虽然建议直接使用 `double`，但是编译器不一定分配为 `double`。

### 示例函数：

- `size_of_type()`：演示内置类型尺寸。
- `print_num()`：演示各种进制字面量。
- `initialization_list()`：演示统一初始化（Uniform Initialization）和防止窄化转换。

需要注意到，某些表达式（例如：`f(x)+g(y)`）与函数参数（例如：`h(f(x), g(y))`）的运算顺序是**未定义**的。

## 1.5 作用域与生命周期

- **作用域**：标识符可见的范围。
- **生命周期**：对象在内存中存在的时间。

ISO C++ 区分了几种作用域：局部作用域、类作用域、命名空间作用域。对象的生命周期则分为：自动（栈）、静态、动态（堆）。

## 1.6 常量

- `const`：大致表示“我承诺不改变这个值”。主要用于说明接口。
- `constexpr`：大致表示“在编译时求值”。主要用于说明常数。

### 示例函数：

- `const_square()`：演示 `constexpr` 函数，可在编译时求值。

- **数组**：相同类型元素的连续序列。
- **指针**：存储内存地址的变量。
- **引用**：对象的别名。
