## 1.2 程序 {#basics_program}

ISO C++ 定义了两种实体：

- **核心语言特性**：例如内置类型（如 `int` 和 `double`）和循环（如 `for` 语句）。
- **标准库组件**：例如容器（如 `vector` 和 `map`）和 I/O 操作（如 `cout` 和 `cin`）。

代码参考：[1_2_program.cpp](../1_basics/src/1_2_program.cpp)

## 1.3 函数 {#basics_functions}

函数是执行某些计算的代码块。它是程序中实现模块化的基本手段。

- **返回类型**：函数返回值的类型。
- **参数**：传递给函数的值。

代码参考：[1_3_functions.cpp](../1_basics/src/1_3_functions.cpp)

## 1.4 类型、变量与算术 {#basics_types}

C++ 是一种静态类型语言，每个实体（如对象、值、变量等）在被使用前必须有明确的类型。

- **内置类型**：`bool`, `char`, `int`, `double` 等。
- **算术运算**：`+`, `-`, `*`, `/`, `%`。
- **初始化**：推荐使用 `{}` 初始化（统一初始化）。

代码参考：[1_4_types.cpp](../1_basics/src/1_4_types.cpp)

## 1.5 作用域与生命周期 {#basics_scope}

- **作用域**：标识符可见的范围。
- **生命周期**：对象在内存中存在的时间。

## 1.6 常量 {#basics_constants}

- `const`：大致表示“我承诺不改变这个值”。主要用于说明接口。
- `constexpr`：大致表示“在编译时求值”。主要用于说明常数。

代码参考：[1_6_constants.cpp](../1_basics/src/1_6_constants.cpp)

## 1.7 指针、数组与引用 {#basics_pointers}

- **数组**：相同类型元素的连续序列。
- **指针**：存储内存地址的变量。
- **引用**：对象的别名。

代码参考：[1_7_pointers.cpp](../1_basics/src/1_7_pointers.cpp)

## 1.8 条件判断 {#basics_tests}

C++ 提供了多种结构来表达条件逻辑：

- `if` 语句
- `switch` 语句
- 循环：`while`, `for`, `range-for`

代码参考：[1_8_tests.cpp](../1_basics/src/1_8_tests.cpp)

## 1.9 映射到硬件 {#basics_hardware}

C++ 的设计目标之一是实现对硬件的高效映射。内置类型和基本操作直接对应于机器指令。
